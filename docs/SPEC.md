# プラズモンカップリングシミュレーター MVP 仕様書

## 文書の位置付け

- 対象リリース：Build Week 提出版（MVP）
- 対象利用者：研究者・学生
- 本書の役割：提出版で提供する価値、機能境界、受入基準を定義する。
- 物理モデルの適用範囲は本書で新設しない。`docs/physics_assumptions.md`、`docs/quantum_corrected_model_integration.md`、`docs/validation_plan.md` を正とし、本書はそれらを実装要件へ展開する。
- 決定済みの数値基準とモデル選択は第9節に記録し、物理パラメータを独自に補わない。

## 1. 目的（Purpose）

本アプリは、均一媒質中の Au ナノ粒子集合体について、粒子径、配置、表面間ギャップ、偏光、媒質屈折率を変えたときの Extinction、Scattering、Absorption スペクトルの傾向を、ローカル環境で素早く探索できるようにする。

対象は、プラズモン結合条件を比較・検討したい研究者、および CDA・QCM の適用範囲を学びながら条件依存性を調べる学生である。本アプリは条件探索ツールであり、実験データの定量再現器、あるいは BEM/DDA/FDTD や TDDFT の代替ではない。

## 2. MVP範囲（In Scope）

Build Week 提出版では、次を実装対象とする。

### 2.1 入力対象とモデル

- 材料は Au のみ、形状は完全な球のみとする。
- 粒子数は 1〜20 個、各粒子の直径は 2〜100 nm とする。粒子ごとに直径と 3D 座標 `x, y, z` を設定できるようにする。
- 背景媒質は均一・等方・非吸収性とし、water、ethanol のプリセットおよび正の実数屈折率 `n_medium` の直接入力を扱う。
- 光源は単色平面波とし、スペクトル計算では真空波長、伝搬方向、直線偏光ベクトルを指定できるようにする。初期の計算波長域は 200〜1500 nm とする。
- 単一球の参照解には完全 Mie 理論を用いる。複数球の相互作用計算には、遅延を含む dyadic Green tensor を使う CDA を用いる。
- 分極率の既定は単一球 Mie 理論の電気双極子散乱係数 `a_1` に基づく FCDA とする。Kreibig 型サイズ補正は切替可能、既定 OFF とする。
- 表面間ギャップが 0.5 nm 以上 1 nm 未満の粒子対には QCM を自動適用する。ユーザーによる無効化は認めない。QCM の理論根拠、パラメータ、適用有無、パラメータ出典は結果メタデータに残す。MVPの距離依存パラメータは、Esteban et al. (2012) Fig. 2dのAu実線をデジタイズした暫定参照表とする。

### 2.2 安全装置と適用範囲の表示

- 表面間ギャップが 0.5 nm 未満なら、UI と API の両方で計算をブロックする。値の自動丸めはしない。エラーには、量子トンネル効果により古典的局所応答モデルが破綻するため計算できないことを明記する。
- 粒子の重なり、負のギャップ、直径範囲外、非有限値などの不正入力を検出し、計算を開始しない。
- 直径 40〜100 nm、またはギャップ 1〜5 nm では近似限界の警告を表示する。ギャップ 0.5〜1 nm の QCM 結果は参考値であることを表示する。
- Kreibig サイズ補正を有効にし、計算窓または主要解析窓が 517 nm 未満を含む場合は、既存の物理前提に従う警告を結果メタデータと UI に表示する。

### 2.3 結果表示と入出力

- `C_ext`、`C_sca`、`C_abs`、`Q_ext`、`Q_sca`、`Q_abs` を波長の関数として求め、Plotly.js を用いて同一画面で比較できるグラフとして表示する。断面積は nm² を基本表示とし、内部計算は SI 単位系で行う。
- 計算の進捗は SSE で UI へ送る。計算完了時にスペクトルを表示し、計算中止時には部分データを保存・出力しない。
- CSV には波長、3 種の断面積、3 種の効率を含める。JSON には粒子、材料、媒質、光源、波長条件、モデル名、材料データの出典、ソフトウェアバージョン、QCM の適用有無とパラメータを含める。暫定デジタイズ表を使用した場合は、原論文・図・対象曲線・校正点・読取誤差・補間法・`provisional_digitized` の状態も保存する。
- 保存した JSON を読み込んで同じスペクトルを再計算できるようにする。

### 2.4 動作環境

- FastAPI、uvicorn、静的 Web UI、ローカル同梱の Plotly.js を用いる既存構成を維持する。
- FastAPI は `127.0.0.1` のみで待受し、UI は同一オリジンから配信する。
- 初回セットアップ完了後は、起動、計算、可視化、出力に外部ネットワークを必要としない。

## 3. 非目標（Out of Scope）

- ナノスター、ナノロッド、ナノキャップなど、非球形状の厳密な電磁場計算
- BEM、DDA、FDTD、TDDFT との完全連携、またはそれらを用いた計算結果の常時生成
- 実験スペクトルのアップロード、直接キャリブレーション、逆問題によるパラメータ推定
- `gap < 0.5 nm` の接触・重なり領域、電荷移動プラズモン（CTP）を含む量子計算
- 基板、吸収性または分散性の背景媒質、粒径分布、凝集動力学、配位子層、表面粗さ、結晶性の厳密な取り扱い
- 多言語 UI、クラウド配信、外部 API・CDN・外部計算サーバーへの通常動作時の依存
- 実験の定量再現や論文用の高精度予測を保証すること

## 5. 優先順位（Priority）

### Must

- Mie 参照計算、CDA 多粒子計算、QCM の必須適用、Kreibig 補正の切替、および物理前提で定められた入力範囲の実装
- 0.5 nm 未満のブロック、粒子重なり検出、QCM・近似限界・Kreibig 警告の明示
- 1〜20 個の Au 球、媒質・光源条件、スペクトル表示、CSV/JSON 出力と JSON からの再計算
- `docs/validation_plan.md` の Test 1〜6 を満たす自動検証
- localhost 限定、オフライン動作、SSE による進捗通知と中止時の部分データ非保存

### Should

- 粒子配置を確認しやすい 2D 上面図。物理計算では 3D 座標を常に保持する。
- water/ethanol のプリセット、カスタム媒質、典型的な二量体条件を設定しやすい入力導線
- 警告・エラー・QCM 適用注記を、結果の読み違いが起きにくい画面設計で提示すること

### Nice

- 配色、余白、アニメーション、グラフの装飾など、結果の物理的解釈を変えない視覚的洗練
- 再利用可能な条件プリセット、見栄えを整えたエクスポート、追加の比較表示

### 優先判断の基準

物理的な正しさ、適用範囲の安全装置、再現性の検証は、UI の見栄えより常に優先する。Must の物理検証が一つでも未達なら、グラフや画面が完成していても提出可能とは判断しない。一方で、入力できない、警告を見落とす、結果を読めないといった UI 上の欠陥は物理的誤用につながるため、単なる装飾ではなく Must/Should の品質要件として扱う。

## 6. 受入基準（Acceptance Criteria）

以下をすべて満たしたとき、MVP の提出判定が可能となる。第9節の数値しきい値は、既存の検証計画に追加する実務上の目安であり、物理精度そのものを保証する値ではない。

| 区分 | 検証可能な受入基準 | 根拠 |
| --- | --- | --- |
| 単一球 | water 中の直径 5、20、50、100 nm の Au 球について、200〜1500 nm で `C_ext >= 0`、`C_sca >= 0`、丸め誤差を除き `C_abs >= 0`、`C_ext = C_sca + C_abs` の相対誤差が `1e-8` 以下、全効率が有限値である。固定したMie基準配列との相対誤差は `1e-6` 以下とする。 | Validation Test 1、D-4 |
| CDA の孤立極限 | 表面間ギャップ 1000 nm 以上から距離を倍増させ、3種の断面積と位相補正済み誘起双極子が単一粒子応答の2倍・孤立応答へ近づくことを確認する。両方の相対誤差は `1e-4` 以下とし、偏光や座標原点で不自然に変化しない。 | Validation Test 2、D-5 |
| 二量体結合 | 同一径二量体のギャップ 2、5、10、20、50 nm と平行・垂直偏光で偏光依存性、連続的な共鳴シフト・強度変化が現れる。ギャップ 5 nm 以下には近似限界の警告が表示される。 | Validation Test 3 |
| QCM と安全装置 | ギャップ 0.3 nm では UI・API の双方が明示的エラーで計算を拒否し、結果・部分データを保存しない。0.5〜0.9 nm では QCM を自動適用してメタデータと UI に注記する。4層と5層の比較を第9節の基準で確認し、暫定デジタイズ表の出典・校正・読取誤差を保存する。1.0 nm 以上では通常の CDA とし、境界付近でスペクトル形状が数値的に不連続に破綻しない。 | Validation Test 4、物理前提、D-2、D-3 |
| 多粒子安定性 | 非重複のランダム配置で 3、5、10、20 個を計算し、行列計算の失敗、NaN、Inf がない。同一設定・同一 seed の再現性があり、粒子順序を変えても物理結果が変わらない。 | Validation Test 5 |
| 入出力再現性 | CSV と JSON に必須列・必須メタデータを含め、保存 JSON から同一スペクトルを再計算できる。QCM 適用有無とパラメータも保存される。 | Validation Test 6 |
| UI と配信 | 利用者が条件を入力し、進捗を確認し、結果グラフと警告を読み、CSV/JSON を取得できる。通常動作時は localhost・同一オリジン・オフライン方針を満たす。 | README、MVP範囲 |

Test 3 にある BEM/DDA との代表条件比較は「可能になった段階で」とされているため、今回の MVP 提出の必須ゲートには含めない。ただし、将来の精密検証では実施候補として維持する。

## 8. 制約条件（Constraints）

- 外部提出期限は **2026年7月21日 17:00 PT（PDT）**、日本時間では **2026年7月22日 09:00 JST** とする。社内運用締切は3時間前の **2026年7月22日 06:00 JST** とする。提出サイトの表示時刻は提出前に再確認する。
- ローカル動作・オフライン実行の方針を維持する。初回セットアップ時の固定依存関係と Plotly.js の取得・ハッシュ検証を除き、通常動作でネットワークを使わない。
- FastAPI + uvicorn + 静的 Web UI + SSE の既存構成を基礎とし、計算ジョブは API/UI の応答を不必要にブロックしない既存の分離方針を維持する。
- 物理計算コアは SI 単位系を用い、UI・API・ファイル入出力の境界で nm 等を変換する。
- Au 光学定数は Johnson and Christy (1972) データを用い、データ範囲外への原則的な外挿はしない。使用データセット名、出典、波長範囲、補間法を出力に残す。
- 新しい物理パラメータや近似式を独自に作らない。QCM の採用式・出典・適用範囲は、コード、出力メタデータ、README に記録する。
- 新規依存パッケージの追加は、この仕様だけでは承認しない。必要になった場合は別途確認を得る。

## 10. 参照文書の整合性メモ

- QCM統合指示書は `docs/quantum_corrected_model_integration.md` に統一した。旧ファイル名は残さず、参照先はすべて同ファイルを正本とする。
- `docs/physics_assumptions.md` は、ギャップ 1〜5 nm を警告表示対象、0.5〜1 nm を QCM 補正対象、0.5 nm 未満を計算不可とする。一方 README の既存記述には、ギャップ 2 nm 未満を一律「参考値」とする旧い分類と、量子トンネル効果を含まないとする記述が残る。MVP の挙動は前者（物理前提）を正とし、README は将来整合させる必要がある。
- Esteban et al. (2012) は `docs/references.md` に登録済みである。Supplementary InformationでAu係数表は確認できなかったため、MVPではFig. 2dのデジタイズ表を暫定参照表として扱う。
- QCM 指示書が示す原論文の非接触領域の目安と、本ツールの QCM 上限 1 nm は一致しない。ただし同指示書はこれを意図的な安全マージンと明記している。本仕様はこの運用ルールを変更しない。

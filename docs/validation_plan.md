# 検証計画・受け入れ基準

## 原則
物理コアは、UIの実装より先にpytestで検証する。
テストがない近似計算は研究用ツールとして採用しない。

## Test 1: 単一Au球のMie計算

条件：
- Au sphere
- water中
- 直径 5 nm、20 nm、50 nm、100 nm
- 波長200〜1500 nm、10〜0.1 nm刻み

受け入れ基準：
- C_ext >= 0
- C_sca >= 0
- C_abs >= 0（数値丸め誤差を除く）
- C_ext = C_sca + C_abs を相対誤差 1e-8 以下で満たす
- Q_ext、Q_sca、Q_abs が有限値である
- 単一球Mie計算の結果を、採用したMieライブラリの基準値と一致させる

## Test 2: CDAの孤立極限

条件：
- 同一Au sphereを2個置く
- 粒子間距離を十分大きくする
- 例：表面間ギャップ 1000 nm 以上

受け入れ基準：
- 2粒子系のC_ext、C_sca、C_absが、単一粒子応答の2倍へ近づく
- 計算した誘起双極子が、孤立粒子の応答へ近づく
- 偏光や座標原点の取り方で不自然に結果が変わらない

## Test 3: 球二量体の結合

条件：
- 同一径Au sphereのdimer
- dimer軸に平行な偏光と垂直な偏光
- 表面間ギャップを2、5、10、20、50 nmで変化させる

受け入れ基準：
- 結果に偏光依存性が出る
- 条件に応じた共鳴シフト・強度変化が連続的である
- `1.0 <= gap <= 5.0 nm` ではCDA近似限界の構造化警告 `cda_gap_limitation` が必ず出る
- 可能になった段階で、代表条件をBEMまたはDDA結果と比較する

## Test 4: 極小ギャップの安全装置とQCM適用（新規）

条件：
- 同一径Au sphereのdimer
- 表面間ギャップを 0.3、0.5、0.7、0.9、1.0、1.2 nm で変化させる

受け入れ基準：
- gap = 0.3 nm（0.5 nm未満）では、計算がブロックされ、
  UI・APIともに明示的なエラーメッセージを返す
- 結果データ・部分データが一切保存されない
- gap = 0.5〜0.9 nm では、QCMが自動適用され、
  結果メタデータに「QCM適用済み」の注記が記録される
- gap = 0.5〜0.9 nm の結果警告はQCM適用状態（`qcm_applied` または
  `qcm_classical_limit`）を示し、`cda_gap_limitation` を同時に含まない
- gap = 1.0 nm 以上では、QCMが適用されず通常のCDAで計算される
- gap = 1.0〜5.0 nm では `cda_gap_limitation` を返し、5.0 nm超では返さない
- QCM適用の有無で計算結果（スペクトル形状）が不連続に破綻しない
  （境界付近で数値的に滑らかにつながることを確認する）
- 物理コアでは `tests/test_qcm.py` が暫定表・Drude局所誘電率・表範囲外の古典極限を、
  `tests/test_qcm_cda_integration.py` がgap 0.5、0.7、0.9 nmでの有限値、
  QCM on/offの検証用比較、5.439 Å境界での補正量の消失、3→4→5層の内部感度を検証する。
  on/off切替は検証専用であり、将来のUI/APIに利用者向けの無効化機能を追加しない。
- `tests/test_api.py` は、`POST /simulate` の正常応答、QCM適用時の必須来歴メタデータ、
  スキーマ違反とgap 0.3 nmの422応答、QCM来歴を構成できない場合の明示的な503応答を検証する。
  このAPIは同期完了後の結果だけを返し、サーバーに部分データを保存しない。`POST /simulate/jobs`、
  `GET /simulate/stream/{job_id}`、`POST /simulate/jobs/{job_id}/cancel` は後述のSSE補助試験で扱う。
- 4層採用の内部離散化基準は、3→4および4→5の各比較で、3断面積の正規化スペクトル差と
  ピーク高さ差が1%以下、ピーク位置差が波長刻み以下であることとする。この基準は
  原論文のBEM/FEMとの一致ではなく、CDA縮約内の数値感度だけを確認する実務上の目安である。

## Test 5: 多粒子安定性

条件：
- ランダム配置のAu sphereを3、5、10、20個
- 非重複条件を満たす複数配置
- 異なる粒径を混在させる

受け入れ基準：
- 行列計算の失敗、NaN、Infが発生しない
- 重なり、負のgap、極端なgapを明示的に検出する
- 同じ設定・同じ乱数seedでは再現可能な結果になる
- 粒子順序を入れ替えても物理結果が変わらない

## Test 6: 入出力の再現性

受け入れ基準：
- CSVには波長、C_ext、C_sca、C_abs、Q_ext、Q_sca、Q_absを含める
- JSONには粒子、材料、媒質、光源、波長条件、モデル名、
  材料データ出典、ソフトウェアバージョン、
  **適用したQCMの有無とパラメータ**を保存する
- 保存したJSONを読み込むと同じスペクトルを再計算できる
- 同一入力を2回計算して生成した正規化CSV/JSON文字列は完全に一致する。CSVの改行はLF、
  列順は固定とする。
- 多粒子集合体の効率は、各球の幾何学的投影面積和
  `A_geo = Σ π (d_i / 2)^2` を基準に `Q = C / A_geo` とし、各CSV行でこの関係を確認する。
- `tests/test_io_reproducibility.py` はQCM適用入力で上記を検証し、JSON往復後も
  `QcmResultMetadata` の必須来歴が欠落しないことを確認する。

## SSE・取消の補助試験

- `tests/test_api_sse.py` は、波長点ごとのSSE進捗イベントが点数と進捗率だけを持ち、
  スペクトルは完了イベントでのみ返ることを確認する。
- `tests/test_cancellation.py` は、取消後に `cancelled` だけを終端イベントとして返し、
  部分スペクトル・結果JSON・ファイル・一時ジョブが残らないことを確認する。
- 取消は進行中の一波長CDA線形ソルバーを途中で強制終了せず、波長点境界で協調的に反映する。
  これは数値ライブラリの安全な終了を優先する運用上の制約である。

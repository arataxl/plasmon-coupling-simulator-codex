# Plasmonic Coupling Simulator (v0.1.0)

複数の金（Au）ナノ粒子におけるプラズモンカップリングと、光学スペクトル変化を可視化・解析するための、ローカルPC実行型研究用シミュレーター。

---

## 既知の物理的制限

本ソフトウェアの物理コアは、結合双極子近似（CDA）に基づいています。そのため、以下の物理的制限および推奨探索領域が存在します。

*   **双極子近似の前提**: 本モデルは電気双極子近似に基づいています。
*   **優先探索領域**: 粒子の直径 **40 nm 以下**、かつ表面間ギャップ **5 nm 以上**。この領域で最も高い物理的妥当性を示します。
*   **半定量的探索領域**: 粒子の直径 **40〜100 nm**、または表面間ギャップ **2〜5 nm**。高次多極子相互作用が無視できないため、スペクトルの傾向を掴む半定量的な分析に留まります。
*   **参考値領域**: 粒子の直径 **100 nm 超**、または表面間ギャップ **2 nm 未満**。
*   **ギャップ 2 nm 未満の制限**: 高次多極子相互作用、非局所応答、および量子トンネリング効果を含まないため、実測値との不一致が顕著になる可能性があり、あくまで参考値となります。
*   **Kreibigサイズ補正の制限**: 補正モデルは感度解析（定性的比較）を目的としており、バルク金自体の帯間遷移（Interband transitions, 波長 < 517 nm / エネルギー > 2.4 eV）におけるサイズ効果は無視されるため、この短波長領域での定量予測には適しません。
*   **0.1 nm 刻みステップの制限**: 高解像度モードにおける「0.1 nm刻み」は数値サンプリング上の密度であり、基礎となる物理モデルや光学定数データセットの「0.1 nmレベルの物理精度」を意味または保証するものではありません。
*   **背景媒質の制限**: 背景媒質（水 = 1.33、エタノール = 1.36、カスタム屈折率）は、指定波長域で波長非分散・非吸収の正の実数定数として取り扱われます。
*   **粒子間ギャップの下限制限（新規追記）**: 表面間ギャップの入力下限は0.5 nmです。
    0.5 nm未満の入力は計算をブロックします。0.5〜1 nmのギャップでは、
    量子補正モデル（QCM, Esteban et al. 2012）を自動適用します。

## 特徴および配信仕様

*   **同一オリジン・ローカル限定配信**:
    *   FastAPIサーバーは `127.0.0.1` (localhost) のみでバインドされ、外部からの不要な通信をシャットアウトします。
    *   WebUI（`web/`）は、APIと同じ同一オリジンから静的配信されるため、CORS設定を追加せずローカルセキュリティ境界を維持します。
*   **オフライン動作仕様**:
    *   初回セットアップ時には、固定パッケージの pip インストールおよび Plotly.js ローカル資産の取得のため、一時的にネットワーク接続が必要です。
    *   セットアップ完了後の `run_app.bat` による通常起動、計算、可視化は、外部CDN・Webフォント・外部APIに依存せず、**完全にオフライン動作**します。
*   **独立した計算ジョブプロセス**:
    *   重い CDA 計算ジョブ（特に高解像度スイープ）を実行する際、FastAPI の API メインプロセスとは別に `multiprocessing.Process` を明示生成する専用ジョブワーカー方式を採用しています。
    *   これにより、計算処理がAPIおよびUIイベント処理の応答ポートを直接ブロックせず、UIの軽快な動作を維持します。
*   **SSE進捗配信とキャンセル指示**:
    *   進行状況（進捗%）は Server-Sent Events (SSE) を通じてリアルタイムにUIへ配信されます。
    *   ユーザーがキャンセルをクリックした場合、物理コアのループ毎に `should_cancel()` が捕捉され、計算が即座に強制終了されます。キャンセルされたジョブの部分データは一切エクスポート・保存されません。
*   **Plotly.jsの同梱と完全性検証**:
    *   バージョン: `2.24.1`
    *   取得元URL: `https://cdn.plot.ly/plotly-2.24.1.min.js`
    *   期待SHA-256ハッシュ: `d5dae4bdea4f17da17c819b04f7ddcf05e3cffd252194cbe89cbbff40ee1d3c7`
    *   ダウンロード時にハッシュ値を自動で検証し、不一致や破損を検知した場合はセットアップが失敗するように設計されています。

## セットアップおよび実行方法

### 1. 初回セットアップ (要インターネット接続)
ワークスペース直下の以下のバッチファイルをダブルクリック、またはコマンドラインから実行します：
```bash
setup_windows.bat
```
*   これにより、Python 仮想環境（`.venv`）が自動生成されます。
*   依存パッケージ（FastAPI, uvicorn, numpy, scipy, pandas, miepython, pytest 等）がインストールされます。
*   Plotly.js が自動的にダウンロードされ、ハッシュ値が検証されたのち `web/vendor/plotly.min.js` に配置されます。

### 2. シミュレーターの起動 (オフライン可能)
セットアップ完了後、以下のバッチファイルをダブルクリック、またはコマンドラインから実行します：
```bash
run_app.bat
```
*   ローカルサーバーが `http://127.0.0.1:8000/` で自動起動し、規定のウェブブラウザでUIが自動的に開きます。

## テストの実行

仮想環境のパッケージおよびサーバー動作をテストする場合は、セットアップ後に以下を実行します：
```bash
.venv\Scripts\python -m pytest
```
*   物理計算コア、条件数警告、Mie理論独立テスト、およびAPIエンドポイント疎通・マルチプロセスキャンセル・SSE進捗配信を含む **全28ケースのテスト** が実行されます。

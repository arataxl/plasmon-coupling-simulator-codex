CONFIGURATION

計算条件

プリセットまたは個別の3D座標を入力し、計算前に配置と表面間ギャップを確認してください。 最大50粒子（21粒子以上は古典CDA・全gap > 5 nm）

Calculation mode

Calculates one homogeneous Au sphere with all electric and magnetic Mie orders. CDA, QCM, and the experimental quadrupole approximation are not used. For 2-100 nm, use it to compare with the close single-particle CDA approximation. Coordinates affect only the shared preview.
